#  Intelligent Math Agent Grok / Ollama (LLM)

**AI-Powered Mathematics Solver & Tutor** (Jupyter Notebook)

An interactive Jupyter Notebook that acts as an **Intelligent Math Agent**. Just type your math problem (in English or Hindi) and get **step-by-step solutions** with clear explanations, LaTeX formatting, and code verification.

###  Features

- Step-by-step reasoning & detailed explanations  
- Supports School, JEE, College & Olympiad level Math  
- Algebra, Calculus, Trigonometry, Geometry, Probability, Statistics, etc.  
- Word Problem Solver (Real-life applications)  
-  Beautiful LaTeX rendering  under working
-  Interactive — ask follow-up questions  

###  How to Use

1. Open `Intelligent_Math_Agent.ipynb`
2. Run the cells
3. Start asking math questions in the chat interface

###  Technologies Used
- Python 3
- Jupyter Notebook
- LangChain / LlamaIndex (Agent framework)
- SymPy, NumPy, Matplotlib
- Grok / Ollama (LLM)
